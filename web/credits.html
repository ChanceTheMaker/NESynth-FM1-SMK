NESynth adds the shared browser/firmware interface, MMC1 and MMC2 support, platform integration and correctness patches. The included diagnostic cartridge is original to this project. Commercial games are not included. The homebrew collection is credited below.

Hardware & website

Built on GameDude and the Felucca/MusicCoach platform. Felucca: Leo Kuroshita / Huegelton Instruments. SMK and Sloop adaptations: Chance Roth / ChanceTheMaker. Shared instrument illustrations and control mappings are adapted for NESynth.

Integration is GPL-3.0-only. Complete corresponding source, build tools, patches and provenance are available on GitHub.
