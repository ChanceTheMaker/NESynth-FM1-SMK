NESynth adds the shared browser/firmware interface, MMC1, UxROM, CNROM, MMC3, MMC2 and Color Dreams support, platform integration and correctness patches. The included diagnostic cartridge is original to this project. Commercial games are not included. The homebrew collection is credited below.

Hardware & website

Built on GameDude and the Felucca/MusicCoach platform. Felucca: Leo Kuroshita / Huegelton Instruments. SMK and Sloop adaptations: Chance Roth / ChanceTheMaker. Shared instrument illustrations and control mappings are adapted for NESynth. The SMK RAM updater and model-specific packaging come from the Doom/Felucca/Sloop SMK updater, with source provenance and GPL notices retained.

Integration is GPL-3.0-only. Complete corresponding source, build tools, patches and provenance are available on GitHub.

Original device firmware

The restore image is the unmodified M-VAVE FM-1 V15 firmware and retains the manufacturer's terms. SMK-37 Pro and Elite use the unmodified official 016 files from a pinned documentation mirror; each model's SHA-256 is verified before use. Manufacturer firmware is separate from NESynth's open-source firmware.
